# Metro Ticket Generating System (ServiceNow)

## 📌 Overview
The Metro Ticket Generating System is a digital e‑ticketing solution built on **ServiceNow**. It automates fare calculation, generates QR‑based tickets, and provides passengers with a seamless booking experience — reducing manual effort and wait times.

## 🎯 Problem Statement
Traditional metro ticketing relies heavily on physical counters, leading to:
- Long queues and delays  
- Manual errors in fare calculation  
- Limited scalability for growing passenger demand  

## 💡 Solution
This system leverages **ServiceNow workflows and catalog items** to:
- Dynamically calculate fares based on stations and journey type  
- Generate secure QR codes for digital tickets  
- Display tickets instantly in a confirmation modal  
- Enable smooth digital checkout without manual intervention  

## 🛠 Tech Stack
- **Platform:** ServiceNow  
- **Frontend:** HTML, CSS, JavaScript (ES6)  
- **Backend:** ServiceNow Catalog Items, Flows, Widgets  
- **Database:** ServiceNow Tables  
- **Version Control:** Git & GitHub  

## 🚀 Key Features
- Automated fare calculation  
- QR code ticket generation  
- Real‑time ticket confirmation modal  
- Reduced dependency on manual counters  
- Scalable for future metro expansions
